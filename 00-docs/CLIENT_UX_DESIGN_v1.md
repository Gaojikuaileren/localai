## 0. 定位

**不是六个并列 AI 工具的启动器,而是两位成年人共用的"家庭操作系统"。**
「主页(今天)」是中心;对话/资产/翻译/课程/电脑与设备/投资研究是管家的**专业工作空间**。
温暖、安静、精致;信息可扫读,不做成塞满小组件的管理后台。

## 1. 已裁定的六条前提(2026-07-29 用户拍板)

| # | 裁定 | 影响 |
|---|---|---|
| **1** | **正式从"单用户"升级为"双成员家庭"** | 引入「人(成员)」身份层;记忆/权限需成员维度 |

| **6** | **待办/家务/扩展 = 独立结构化数据**,不进记忆库 | 共享可见范围轴 |

### ★ 由此产生的 P3c 硬前置(新)
**身份层要从「设备」扩到「设备 × 成员」。** P3b 认证的是**设备证书**,系统并不知道此刻坐在设备前的是 A 还是 B;
而「仅本人」与「成员二次确认」都需要**人**这一层。**P3c 开工前必须先补这一层**,否则 §6 的隔离落不了地。

## 2. 三层可见范围(禁止混用"私人/保密")

| UI 名称 | 家庭主页/简报 | 另一成员默认视图 | 另一成员主动查看 | 入口/通知/痕迹 |
|---|---|---|---|---|
| **家庭** | 出现 | 出现 | 可 | 可见 |
| **个人** | 不出现 | 不出现 | **可**(主动) | 可见其存在 |
| **仅本人** | 不出现 | 不出现 | **不可** | **零痕迹** |

**投资研究 = 仅本人 + 端限定**:非指定成员/非指定端**看不到导航行、工作区名、通知、摘要、活动记录、后台任务摘要、家庭搜索命中**——**任何痕迹都没有**(不是灰掉,是不存在)。

**两轴交互**(可见范围 × 敏感度):
```
              S0/S1 普通            S2 机密(地址/健康/亲属)
家庭          家庭可见普通事实       家庭可见但机密渲染(值 withhold,溯源留)
个人          本人默认 + 对方可查    同左 + 机密渲染
仅本人        真正私密              真正私密 + 机密渲染(投资即此格)
```


## 4. 主页(= 今天)

**信息层级**:①问候 + 个人简报 → ②天气与时间 / 下一个家庭日程 → ③正在进行的项目 / 我的待办 → ④任务架 · 设备状态。

### 4.1 天气与时间(★ 分层,不互相牵就)
- **天气 = 三城完整信息**:科隆(家)· 武汉 · 札幌 —— 各显 天气/温度/最高最低/降水提示。
- **时间 = 四地等位一条**:科隆 · 武汉 · 札幌 · **纽约** —— 各显 城市/当地时间/昼夜/相对时差/星期。
- ★ **设计理由**:纽约无天气。若硬塞进"天气行"的栅格会留下空格子 = 视觉残缺、地位不平等。
  分层后纽约是**时间条里平等的一格**,问题消失。
- 时区用 **IANA**(`Europe/Berlin`/`Asia/Shanghai`/`Asia/Tokyo`/`America/New_York`),**禁写死 UTC 偏移**,冬夏令时由库处理。
- 数据 **Open-Meteo**(官方 `openmeteo` TS SDK 候选 · Meteocons 图标候选),**主机统一取+缓存,LAN 客户端读本地结果**;
  只发**预配置坐标**,不发文字地址;卡内保留 `Weather data by Open-Meteo.com` 署名;
  **离线/异常显缓存 + 更新时间 + stale 标记,绝不伪造实时**。

### 4.2 每日简报
应用**每天第一次打开**生成;**每成员每本地自然日最多主动展示一次**;关闭再开**不重复弹**;留在主页可回看。
**个人简报只给本人;家庭简报只含家庭范围内容。**

### 4.3 正在进行的项目(★ 主页最实用的一块)
跨空间列出**可恢复的工作**(一个对话线/一个资产项目/一份课件草稿),**点开直达那个项目**(深链,不用先进空间再找)。
- 只列**当前成员自己的 + 家庭的**;**绝不**出现另一成员的个人/仅本人项目。
- 与**底部任务架**分工:项目 = 回到工作(持久);任务架 = 正在跑的计算进度(短时,空闲隐)。
- 每项显示**可见范围标识**(家庭/个人/仅此端)。

### 4.4 待办与家务
个人待办 · 家庭事务 · 可分配家务。
- 「**提醒我**…」→ 建**个人待办** + 立即**可撤销** +「修改」「移入家庭事务」;
- 「**提醒我们**…」→ **家庭事务**;给对方派活 → 自动家庭事项 + 标负责人。
- 卡片显示 负责人/截止/范围/**来源(AI 记的 vs 成员创建,低调可辨)**/完成状态/修改历史。

### 4.5 日历(**只做占位**)
**禁止**实现本地日历或伪造同步。占位必须明写:**「Apple 家庭共享日历:计划接入,目前未连接。」**
未来接**家庭安全管理员 Apple 账户中的一个家庭共享日历**;**不是两套独立个人日历**,而是一份共享日历用**颜色/成员标记**区分 A/B/双方。
日程对象预留字段:`creator · owner(A/B/both) · color_tag · visibility · source · sync_status · modified_by/at · version_restore`。
改**与对方相关**的日程 → 只能发**邀请/修改建议**,由相关成员接受;普通家庭事项双方均可确认。**不得显示伪造日程或伪造同步成功。**

## 5. 工作空间(六个)的统一骨架

### 5.1 ★ 标签页模型(Chrome 式,不用下拉菜单)
1. 点左侧某功能 → 先看**「开始新任务」+ 过往任务预览**;
2. 点开某任务 → 该任务成为**顶部一个标签页**,**可关闭、可多开**;
3. **再次点左侧该功能** → 回到「新任务 + 记录预览」(不丢已开标签)。

### 5.2 共同规律
- **界面→模型意图**(D42.6):切空间发「期望组件集」意图给 Broker;冲突**弹选择不静默抢**;手动勾选是逃生口。
- **出境**:资产云生成/联网搜索 = **每任务放行**;天气 = **固定白名单端点**;统一走 D39 出境闸 + §5.6。
- **审批**:AI 直接落盘/执行 = **哈希绑定批准**(内容变了就不执行)。
- **急停**:凡涉操控,全局急停**位置与语义皮肤不可改**。

| 空间 | 骨架 | 备注 |
|---|---|---|
| 对话 | 消息流 + 当前模型 + 记忆面板入口 | E1 入口凭证检测(已实装) |
| 资产工坊 | 描述→生成→三池(草稿/采用/导出) | 云生成需放行;复用 P9 |
| 翻译 | 语言对(中日/中德/日德/中英/日英)× 详细解释/快速 | **译文默认不进记忆** |
| 课程与演示 | 大纲→**HTML 幻灯(非 Office)**+ 课件预设 | 直接落盘依赖 P6 |
| 电脑与设备 | AI 操控本机(引导/直接)+ **Device Hub 串流** | 见 §6.3 |
| 投资研究 | **仅本人 · 端限定 · 隐藏占位** | 不实现功能 |

## 6. 家庭身份 · 安全交互

### 6.1 成员与角色
两成员各有档案 + 家庭共享空间;**普通功能平权**;**一名家庭安全管理员**管安全/设备信任/扩展/主机设置。
**每台设备有默认成员**。当前成员 = 设备默认 + **语音语言猜测**(A 常说中文 / B 常说日语),
顶栏显示低干扰「当前识别为 A ·〔纠正〕」。**UI 语言跟随设备设置,不随说话者切换;语音回答可跟随识别语言。**
**语音识别不是身份认证。** 桌面宠物是同一管家人格,外观随皮肤,**不作认证手段**。

### 6.2 AI 可读的家庭上下文(★ 新增规则)
天气/时间/日历/设备状态/任务作为**只读环境上下文**喂给 AI(管家才能自然地说"你周四有家庭晚餐")。三条约束:
1. **上下文 ≠ 记忆**:实时/引用型数据**不写入记忆库**(否则每天天气/每条日程都灌进去,污染记忆并触发机密定级)。
2. **日历遵守可见范围**:在 A 的会话里,AI 只见 **A 的个人日程 + 家庭日程**;**永不见 B 的个人、永不见任何仅本人**。
3. **读进来 ≠ 能漏出去**:出网仍走**每任务放行 + 出境清洗**(与"记忆内容绝不随搜索词出门"同条)。
→ 设置内提供「**AI 可读的家庭上下文**」面板,逐项列出并可开关(看得见的边界)。

### 6.3 设备串流(Device Hub · 未来 IA,不实现技术)
归「电脑与设备」,**不属于家庭大屏模式,不提前进 P3c**。
未来:家庭内受信 PC → 另一受信 PC 串流,建立后默认允许控制,可配「始终允许另一成员」。
- **受控端恒显**:串流边框/状态条 · 控制方身份 · 会话时间 · **本地急停**(即便"始终允许"也不隐藏)。
- **敏感窗口**(密码输入/锁屏/银行/IBKR/系统安全)→ **暂停/遮黑/重新确认**。
- **默认不含**录屏/麦克风/系统音频/剪贴板/文件传输(各自单独设计 + 授权)。
- 全会话**可审计记录**;急停位置与语义**皮肤不可改**。

## 7. 主题系统

**基础设计变量**(定义一次,不为每皮肤写死页面):8px 间距网格 · 字体栈同时支持简中/日文/拉丁 ·
普通动效 150–220ms / 面板切换 280–360ms · 支持减少动态 · **高密度表格与安全确认窗避免大面积毛玻璃** ·
**风险语义色跨主题恒定** · 键盘导航/焦点态/对比度/SR 标签进设计。

★ **禁止大面积半透明/毛玻璃**(用户裁定:增加显存压力)——覆盖层与卡片用**实色**。

| 皮肤 | 调性 | 图标 |
|---|---|---|
| **微风 Breeze(苹果风,默认)** | 清爽留白 · 柔和蓝 · 克制 | 线性图标 |
| **墨白 Ink(黑白极简)** | 纯黑白 | **黑白线性图标(项目自制)** |
| **暖萌 Warm(可爱风)** | 暖奶油 · 珊瑚/薄荷 · 大圆角 · 宠物更萌 | **emoji / 彩色图标** |

**每台设备独立选皮肤**;皮肤设置在 **设置 › 外观**(浅色/深色/跟随系统 + 舒适/紧凑密度)。

**皮肤禁改**:导航结构 · 审批顺序 · **急停位置** · 安全/风险色含义 · 当前成员标识 · **家庭/个人/仅本人标识** · 串流与远控状态 · 高风险确认语义。

## 10. P3c 验收测试场景(无后端也可验 UI/状态契约)

1. **可见范围隔离**:B 会话里搜索/简报/最近/任务架**任何位置**都命不中 A 的「仅本人/投资」——渲染树里**零节点**。
2. **投资完全隐藏**:非指定成员/端**无该导航行**(不是灰掉);切到指定端才出现。
3. **身份不确定**:语音识别与设备默认不一致 → 低干扰提示 + 一键纠正;**看仅本人/远控前必弹成员二次确认**,语音答不算数。
4. **简报节流**:同成员同自然日多次开应用 → 只主动弹一次;跨日再弹;回看不算。
5. **日历不伪造**:占位显「未连接」;任何情况下**无假日程/假同步成功**。
6. **天气离线**:断网 → 缓存 + `updated_at` + stale;**无假实时**;出站 payload **只有坐标无文字地址**。
7. **皮肤不改安全**:切三皮肤 → 导航序/审批顺序/急停位置/风险色/成员与范围标识/串流状态**逐项不变**(快照对比)。
8. **标签页模型**:点任务→顶部标签;可关可多开;**再点左侧功能回到「新任务+记录预览」且不丢已开标签**。
9. **待办来源与撤销**:「提醒我」→个人待办+可撤销+可移入家庭;「提醒我们」→家庭事务;派活→家庭事项+负责人。
10. **权限差异**:非管理员改扩展安全权限 → 只读 + 「只能由家庭安全管理员在主机上更改」。
