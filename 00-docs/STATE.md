### BitLocker 操作清单(需你执行)

> **恢复密钥不是系统里已有、等你去找的东西。它在启用时生成,必须由你当场决定存到哪。**
> 存错地方(比如存在被加密的那块盘上)等于没存。

**① G: 移动盘(先做,它在阻塞 `backup.ps1`)**

1. 资源管理器 → 右键 `G:` → **启用 BitLocker**
2. 选「使用密码解锁驱动器」,设密码
3. **备份恢复密钥** —— 三选:保存到 Microsoft 账户(等于交给微软,按 §4.11.5 D2 判据属出境)/
   **保存到文件**(★ 不能存在 G: 自己身上,也不能存 D:/E:)/ **打印**(★ 最符合 §8.5 铁律 2)
4. 加密范围:G: 已用约 470 GB。选「**整个驱动器**」要几小时(建议睡前跑);
   「仅已用空间」快但删除文件的残留区域不加密
5. 加密模式选「**兼容模式**」(移动盘要能在别的机器解锁)

⚠ G: 上有 `.meine 20260706` 与 `.Shuna 20260706`。加密不动数据,但**以后每次插上都要输密码**。

**② C: 系统盘(D9 方案 A1)**

控制面板 → BitLocker 驱动器加密 → 启用。TPM 已就绪 → **TPM-only 模式,开机自动解锁不用输 PIN**。
同样要保存恢复密钥。

**③ C: 完成后,把记忆卷设为自动解锁**

```powershell
Enable-BitLockerAutoUnlock -MountPoint "D:"
```

**④ D9 的三条配套(必须一起做)**

- BIOS/固件更新前先跑 `Suspend-BitLocker -RebootCount 2`
- **恢复密钥离线两份,不同物理位置,一份在家中可取处** —— 否则 fTPM 出问题时你人在外面就彻底进不去
- 「C: 进恢复模式」写进 §4.11.6 故障表

**查看已启用卷的密钥**:`manage-bde -protectors -get C:`
