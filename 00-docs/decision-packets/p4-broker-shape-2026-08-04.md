## 1. 裁定一:租约**不挺过**中枢重启 ⇒ 进程内单写者

**理由(裁定时的论证)**:租约的全部意义就是「持有者死了就过期」,而**中枢重启意味着每个持有者都已经死了**。
一份能挺过重启的租约表,重启后第一件事必然是把所有条目判死 —— 那它挺过来的只是一堆待清理的墓碑。

**实现形态**:进程内单写者 + 一把 `asyncio.Lock`。D37 的两条 SQL 纪律**翻译成进程内等价物**,不是丢弃:

| D37 原文(SQL 形) | 进程内等价物 | 为什么不能省 |
|---|---|---|
| 条件写 `WHERE holder=:me AND fence_token=:tok` | 续租时在**锁内**比对 `lease_id + fence_token`,不匹配返回可区分的 `NOT_HOLDER` | 「续租」与「重新发放」必须长得不一样,否则一个过期持有者能靠续租把自己复活 |
| `rowcount = 0` 即刻自隐 | 同上:`NOT_HOTER` 是**明确返回值**,调用方据此自隐,不得当成"重试一次" | 静默重试 = 双持有 |
| `clock_timestamp()` 而非 `now()` | **任何时间值不得在拿到锁之前捕获,也不得跨两条租约复用** | `now()` 在 PG 里的危害是"整个事务共用一个时间戳";进程内的等价危害是"在 handler 顶部取一次 `t` 然后在循环里复用" —— 形状一样 |

★ **过期用惰性求值,在锁下算,不设收割线程** —— 收割线程 = 第二个写者 = 双持有从侧门回来。

**代价(如实记账)**:`fence_token` 不再跨重启单调。缓解:token 每次发放**全新**、不复用、
**不由 holder 推导**;重启后世代号从 0 重来,而客户端拿着旧世代号提交会得到 409 + 全量快照,
行为与"世代号对不上"完全一致 —— 这条路径本来就要实现。

**收益**:`10-core/gpu-broker` 的 83 条断言**继续留在 `run-tests.ps1` 的 fast 层**,
仍进 pre-commit。若选 PG 方案,它会掉进 manual 层(需 `ai-gpu` 账户 + 改 `pg_ident`/`pg_hba`),
从此**每次提交不再自动跑** —— 那正是本日刚建 CI 想消掉的状态。

## 2. 裁定二:Broker **直接进 `gateway.py`**,不新起进程

**理由**:
- 复用已有且**已被断言守住**的三样:`ROUTE_TIERS` 反向全表(新路由不归类即判红)·
  档位判定(`classify_caller` allowlist)· 成员表主体解析(客户端自报 tier 一律忽略);
- 保住 §8.1 规则 18「**预览与准入必须是同一段代码**」—— 反代方案下网关不得自己再算一遍,
  而"不得再算一遍"是一条**靠自觉**的约束;同进程则是结构性的;
- 不新增第二套认证与进程管理。

**代价(如实记账)**:GPU 状态与 300 秒流式聊天连接**共处一个进程**。
⇒ 约束:Broker 的锁**只保护状态转换,绝不跨 await 网络 I/O**;采样器是独立 task,
崩溃不得带倒事件循环(异常必须被捕获并进 `DEGRADED_SAFE`,而不是让 task 静默死掉 ——
静默死掉的采样器 = 快照永远停在旧值,而调用方以为它是新的)。

★ 与 §8.1「P2–P5 空窗期不开临时 HTTP 端点」不冲突:那条禁的是**新开一个端口**;
本裁定不新开端口,只在既有网关上增路由,且每条都要进 `ROUTE_TIERS`。

## 4. 本包**不**裁定的(仍待用户)

1. **动态闸公式**:D37 原式 `Σpeak(已装 + 已预留) + peak(新请求)` vs 现码「只算本次新占」——
   两者恰在**已预留未装载**处分歧。★ 已定位陷阱:把 `loaded ∪ reserved` 塞进现有那个单一
   `resident` 参数,会让每个已预留组件被**双重扣减**(既排除在 incoming 外、又还没出现在 NVML free 里)
   ⇒ **两个客户端双双获批** —— 正是 D37 ④ 要关的竞态,从关它的那个参数里重新打开。
2. **租约 kind 词汇**:§8.1.7 的 `WARM/MAINTENANCE` 与 §8.1.6 的 `blocking_set` 是两套并存且互不映射的词。
   ★ 无论选哪套,**新增 kind 的默认必须是「不可驱逐」**。
3. **词表桥的归属方向**(S2)。
4. **A7 显示配置**(S6,不可回填)· desktop_floor 统计量 · 驱动口径。
