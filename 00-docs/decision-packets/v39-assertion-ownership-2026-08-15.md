## 5. 顺带咬到的一条真缺陷:`NoComments` 会让 `CodeOnly` **整个反过来**

**这不在本车道边界内,只登记不改。**

`admin/Selftest.cs` 的 `NoComments()` 是**逐字符**扫 `//` 的,**不认字符串字面量**。
于是 `app/Views/DevicesView.cs:134`:

```csharp
var edgeUrl = $"https://{host}:{dial.Split(':')[1]}";
```

里那个 `//` 被当成注释起点,**从它到行尾整段删掉** —— 连同那个收尾的引号。

实测自证(临时探针打出来的):

```
raw 引号数 = 254(偶)   NoComments 之后 = 217(奇)
CodeOnly(dv) 长度 4832 / NoComments 长度 16198
CodeOnly 里:ClientPairCard=有  ChangeDialRow(=无  KnockAsync=无  _pickedNic=无
CodeOnly 尾部实际内容 = 一串**中文界面文案**(本该被剥掉的那一半)
```

⇒ 引号奇偶一坏,`CodeOnly` 的状态机从那一处起**把代码当字符串、把字符串当代码**。
**后果**:任何 `!CodeOnly(整份源码).Contains("…")` 在这类文件上会**静默恒真** —— 一条假绿。

**今天没有踩到**:本仓用 `CodeOnly` 的地方(如 `SelftestMoved.cs` 那条 ③b-④
`!CodeOnly(pairEntry).Contains("IsHostMachine")`)喂的是**切片**,切片从一个平衡点重新开始,
实测 `CodeOnly(pairEntry)` 正常。⇒ 是**埋着的**,不是正在爆的。

> ★ ASSERTION-PITFALLS 第 3c 条记的是「`CodeOnly`/`NoComments` 用反方向」,
> **这是新的一种**:`NoComments` 自己不认字符串,于是把 `CodeOnly` 弄反。
