## 5. `memory.json` 三条纪律

落在 `admin/Services/MemoryStore.cs`:

1. **先复制、验完再删原件**:`File.Copy`(不是 `Move`)→ 比 **内容哈希**(逐字节)**加**
   **条目数**(解析得出来)→ 两条都过才 `Delete` 原件。
   ★ 只比哈希不够(只说明复制没坏,不说明读得懂);只比条目数也不够(两份都读不懂时同为 0,恒真)。
2. **幂等**四格表,逐格写死不合并:原件不在+目标在 ⇒ 什么都不做;原件在+目标不在 ⇒ 迁;
   **两个都在 ⇒ 以目标为准并把原件改名留证**;两个都不在 ⇒ 空库起步(不是失败)。
3. **失败要看得见**:`LoadOrNull()` 在失败时**返回 null 而不是空表**,
   `App.SaveMemory` 在失败时**绝不存盘**(存一份空的过去,就把「读不到」变成了「真的没有了」),
   「记忆库」页顶上显示 `MemoryStore.Notice`。
