## §1 `$Out` —— 缺陷、修法、为什么这次不会再过期

### 1.1 缺陷(实况,不是推测)

`90-ops/lan/P4-acceptance-checklist.md:23` 与 `:57` 早已把它写死了:

> `build-client.ps1` 的 **`$Out` 默认值一直是 `client-pack`**,V22 **只改了 `$AdminOut`**。
> ⇒ 无参跑一次,客户端落在 `dist\client-pack\`,而**部署位 `dist\client\` 原地不动**。

后果不是"名字不好看":**管理端落位、客户端不落位 ⇒ 每出一次包,两个目录的戳就分裂一次。**
那张清单为此在同一节里连写错三次方向,第三次把**当天最新的**客户端包称作「上一轮的残留」,
最后只好加一条「本节从此不写死任何版本戳」—— **拿纪律去糊一个机械缺陷**。

### 1.2 修法:目录名从源码抠,不写第二个字面量

与 `[3b]` 同一个手法、方向相反 —— 两个 exe 各有一条**逐字探测**,互为镜像:

| 方向 | 探的路径 | 常量出处 |
|---|---|---|
| 客户端找管理端 | `<客户端 exe 目录>\..\admin\localai-admin.exe` | `AdminApp.AdminDirName`(具名常量) |
| 管理端找客户端 | `<管理端 exe 目录>\..\client\localai-client.exe` | `ClientLink.ClientExePathNextTo`(★ **裸字面量**,没有具名常量) |

⇒ `build-client.ps1` 现在用正则从 `ClientLink.cs` 那条探测里把 `"client"` 抠出来当默认 `$Out`。
**抠不出判红,不许静默用 `'client'` 兜底** —— 兜底会让这个洞再躺一版,而它已经躺过一版了。

★ 为什么不去 `ClientLink.cs` 里加一个具名常量(那才是最干净的):**`20-client-win/**` 不在本车道边界内**。
抠字面量是**只读**的,不越界;代价是正则比读常量脆。⇒ **登记一条建议**:
哪条车道下次动 `admin/Services/ClientLink.cs`,请顺手加 `public const string ClientDirName = "client";`
并让 `ClientExePathNextTo` 用它,然后把本脚本的正则改成读常量 —— 与 `AdminApp.AdminDirName` 对称。

★ 带 `-Out` 仍然允许(有意出一份去别处比对),但会当场黄字说清「这不是部署位」。

### 1.3 实证

```
[3b] 验:客户端旁边找得到管理端…
     OK 目录名与 AdminApp.AdminDirName 一致(admin)
     OK 客户端会去看的那个目录,就是这一次发到的目录(…\dist\admin)
=== 出包完成 ===  …\dist\client   版本戳 20260809-2355+c340b3d
```

| 目录 | 出包前 | 出包后 |
|---|---|---|
| `dist\client` | `20260809-1314+0f9fa1c`(落后 main 24) | **`20260809-2355+c340b3d`** |
| `dist\admin` | `20260809-1738+4044671`(落后 main 10) | **`20260809-2355+c340b3d`** |

**两个目录第一次由同一次构建同时落位,且戳 = `main` 的头。**

## §7 `dist/host` 的判断:**登记待办,本轮不补发布步骤**(代价已量)

**代价不是"多两条 `dotnet publish`"**,而是这三条:

1. ★★ `dist/host` 里 **6 个文件全仓找不到第二份**:`吊销测试.cmd` · `启动Edge.cmd` · `续签服务器证书.cmd` · `重置并铸身份.cmd` · `主机-开机上线.txt` · `续签验证清单.txt`
   (只有 `renew-server-verify.ps1` 在 `10-core/identity/host-tools/` 有对应物)。
   ⇒ 补 publish 只重出**二进制**,重不出**操作面** —— 那会给人「`dist/host` 已经可重出了」的**假象**,而它没有。
2. ★ 这 6 个里有 **3 个入不了库**:`主机-开机上线.txt`(6 行绝对路径 + 3 行写死 IP)、`重置并铸身份.cmd`(2 行绝对路径)、`启动Edge.cmd`(1 行 IP)。
   pre-commit 的绝对路径豁免只覆盖 `*.md` / `00-docs/*` / `config/paths.toml` ⇒ `.cmd`/`.txt` 放进 `10-core/` 或 `90-ops/` **会被当场拒绝,而且拒得对**。
3. ★★★ **重出会换掉一个没有任何断言守着的活部署件**:V25 的副机归因有一半在**当前那个** `localai-lan-edge.exe`(2026-08-06)里,而全仓**没有一条断言跑在 `dist/host` 上** —— 换坏了不会有东西红。

**⇒ 正确的第一步不是加 publish,是把操作面纳入版本控制**,顺序:
① 先入库那 3 个干净的(`吊销测试.cmd` · `续签服务器证书.cmd` · `续签验证清单.txt`);
② 另 3 个按 `config/paths.toml` 参数化后入库;
③ 这时再谈 publish 步骤,并同时给 `dist/host` 补第一条断言。
★ `dist/_backup-20260806` 在 ③ 完成之前**不许删** —— 它是今天唯一的回退点。
