## §1 ① 那三个名字今天应该是什么

### 1.1 结论:**不是拼错,是编的**

`20-client-win/app/Services/InterpretState.cs`(交付后在 **`:254`**;本次改动前是 `:178`):

```csharp
public static readonly string[] RequiredModels = { "asr-streaming", "translate", "tts-voice" };
```

仓里**真实的词汇只有两套**,两套都是唯一数据源:

| 词汇 | 权威文件 | 成员 |
|---|---|---|
| 网关别名 | `10-core/gateway/registry.toml` | `assistant.fast` · **`assistant.voice`** · `assistant.deep` · `assistant.vision` · `assistant.resident` · `embedding.default` · `rerank.default` · `escalate.cloud` · `image.concept` · `image.texture` |
| 显存组件 id | `config/vram-budget.toml` | `llm.assistant.8b@{8k,16k,32k}` · `llm.assistant.30b-a3b@32k` · **`speech.lite`** · **`speech.full`** · `vlm.small` · `comfyui.sdxl{,.lowvram}` |

逐个对:

- **`translate` —— 仓里根本没有"翻译模型"这个东西。** 两套表里都没有;
  翻译是**由 LLM 做的**。所以这个名字指的不是一个拼错的组件,是**一个从未存在过的组件**。
- **`asr-streaming` / `tts-voice` —— ASR 与 TTS 不是两个独立组件。** 两者都住在
  `speech.lite` / `speech.full` 里(`vram-budget.toml:128-140`:「turbo ASR 2.07 GPU + Piper CPU TTS 0」)。
  ⇒ 没有一对一的目标可以改过去。
- 额外:`streaming` 这个词今天也不成立 —— P5 落的是**半双工「按住说话」**(整段送 faster-whisper),
  不是流式。

⇒ **诚实的清单是 2 项而不是 3 项**(一个 `speech.*` + 一个 `llm.assistant.*`),
而且**它不该由客户端来维护**(见 §1.3)。

> ★ **措辞更正**(初稿这一节的标题写着「所以『改对』这个选项不存在」,那是话说过了):
> 「把内容改成真 id」在**技术上做得到** —— 改内容能编过,不像删符号那样编不过。
> 它不被采用是因为**另外两条**:
> ⒜ 改完 `Length == 3` 当场判红 ⇒ **门禁 FAIL≠0**,而那条断言在别的车道手里(§1.4);
> ⒝ **改对了也还是错的形状** —— D84 裁定二说客户端**根本不该持有这份清单**。
> ⇒ 不存在的不是"改对"这个动作,而是**"改对之后它就对了"这个结果**。
> 这个区别要紧:派工单写的是「改对**或**删掉」,而**只有"删"是真被堵死的**,
> "改"是被我按 ⒜⒝ 判为不值得做 —— 那是**判断**,不是**不可能**,该说清是哪一种。

### 4.2 ★ 这道题问的是什么(用大白话)

系统里有一个「**这话是你亲口说的**」的标记。带这个标记的内容比别的来源更被信任 ——
将来它可以直接写进你的记忆,不用再问你一次。

**今天决定谁能贴这个标记的规则是:「只要是从这台电脑本机连过来的,就算是你亲口说的。」**

问题是,**这台电脑上跑的不只有你的麦克风**。P6 要上的那个替你跑腿的程序,
也跑在这台电脑上 —— 按今天的规则,**它说的话也会被标成「你亲口说的」**。

### 4.3 三个选项 · 你会经历到什么不一样

| | 选项 | **你会经历到什么** |
|---|---|---|
| **A** | **先不动**(今天照旧) | **今天你什么都不会察觉。** 将来语音接进记忆之后:你翻自己的记忆时,程序替你记下的话和你自己说过的话**长得一模一样**,你分不出哪句是你说的。想改的时候也无从下手 —— 因为看不出哪条是怎么来的。 |
| **B** | **给语音这条路配一把钥匙**(只有拿钥匙的才能贴那个标记) | **平时你察觉不到任何区别。** 唯一会变的是:哪天钥匙没配好,**听写会停下来并告诉你"钥匙不对"**,而不是默默继续。代价 = 多一个可能在开机时坏掉的东西。 |
| **C** | **把「亲口说的」这个档位收窄**(本机连过来 ≠ 自动算你说的) | **你会感觉到记忆里少了一些自动记下来的东西。** 语音转写出来的话不再自动进记忆,要么降一档存,要么每次问你一句"这条要记下来吗"。好处是记忆里的每一条你都认得出来路;代价是多按几次确认。 |

**★ 需要你裁的就一句:P6 那个替你跑腿的程序说的话,该不该和你亲口说的话享受同一个信任档位?**
