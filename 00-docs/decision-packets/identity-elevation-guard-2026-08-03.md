## 1. 事情是怎么撞上的

用户报「我这台就是主机,为什么客户端显示这台不是主机」。查下来:本机确实持有中枢身份
(`{state}/identity/hub.json`,hub `f6hsduipeesexb6f`),只是 lan-edge 没启动。

我试着替他把 Edge 起起来 —— **起不来**。用 `explorer.exe` 拉起(本项目躲开提权护栏的既有办法)
也没能脱掉提权,`localai-lan-edge.exe` 直接:

```
✗ 检测到以【管理员】身份运行 —— 本程序不能用管理员跑。
  身份密钥(CA)在你普通用户的 TPM 上下文里,管理员进程访问会报「密钥集不存在」。
EXITCODE=3
```

**这条护栏是对的,而且救了场。** 问题是:**它只存在于 lan-edge 一侧。**

## 2. ★ 真正的缺口:`localai-identity` 完全没有这道护栏

- `10-core/lan-edge/Program.cs` 里 `RunLan` 开头就检查(搜「检测到以【管理员】身份运行」),
  提权就 `exit 3`;
- `10-core/identity/Program.cs` 的子命令分发表(搜 `"init" => Init()`)前面**只有 args 解析**,
  没有任何完整性等级检查。

⇒ **提权跑 `localai-identity init` 会一声不响地成功**,还照常打印 hub id,
把 CA 铸进 High 完整性上下文。

### 2.1 为什么这比"起不来"严重得多

失败发生在**很久以后、而且指错地方**:

1. 用户在提权终端里跑完 `init` —— 一切看起来正常;
2. 之后按验收清单用**普通用户**起 Edge —— lan-edge 那道护栏这时**不会响**(他确实没提权);
3. 一直要等到 `approve` 那一步才炸出「密钥集不存在」——
   这句话完全指不到真正的原因(「你当初是用管理员铸的」)。

`20-client-win/app/Services/Elevation.cs` 文件头记着这件事:**当时烧掉了一整轮排查。**

而且**不可回退**:唯一出路是 `dist\host\重置并铸身份.cmd` 把身份删掉重铸,
**所有已配对设备全部要重新配对**。代价远高于一条提示。

## 3. 请 **core 车道**做的(护栏)

给 `localai-identity` 补上与 lan-edge **同款**的检查。至少覆盖会碰 CA 私钥的子命令:
`init` / `renew-server` / `revoke-device` / `add-member`。

```csharp
// ★ 与 lan-edge run-lan 同款:CA 私钥绑定【创建它时的完整性等级】。
//   提权铸出来的身份,普通用户跑的 Edge 永远打不开 —— 而失败要到 approve 那一步才炸出
//   「密钥集不存在」,完全指不到真正的原因,且只能重置重铸、所有设备重配。
//   ⇒ 必须在【铸之前】fail-closed,文档挡不住(见本决议包 §4)。
if (IsElevated())
{
    Console.WriteLine("✗ 检测到以【管理员】身份运行 —— 铸身份必须用普通用户。");
    Console.WriteLine("  CA 私钥绑定创建它的完整性等级;管理员铸出来的身份,普通用户的 Edge 打不开。");
    Console.WriteLine("  请在【普通】终端里重跑。");
    return 3;
}
```

★ 复用 lan-edge 里已有的那个判断,不要各写一份 —— 两份迟早会漂。

### 3.1 验收断言(否则这条改动本身没被钉住)

- 提权跑 `init` 必须 `exit 3` 且不产生任何 identity 文件(**不能只拒绝、却已经写了一半**);
- 普通用户跑 `init` 不受影响;
- 按项目纪律:先把检查改坏、确认断言变红,再改回。

## 4. 请 **ops 车道**做的(文档,但只是补充,不是替代)

`90-ops/lan/S6-acceptance-checklist.md` 的 `## 0. 准备(主机)`(截至 `b521b66`,行 8-12):

改三处(都在这一节里):

   lan-edge 自己会拦(见 §2),但清单不该把人往坑里带。

★ 但文档只是补充:**只有 §3 那层是真的 fail-closed。** 今天的教训正是"照着文档做的人也会踩" ——

## 5. 顺带记一条给所有车道的实情

**`explorer.exe <path>` 从提权进程拉起,并不保证脱掉提权。**
客户端那条部署回路一直有效(`用 explorer 拉起` 绕开 D46),但对 `dist\host\启动Edge.cmd`
今天实测**没有生效** —— Edge 仍然检测到管理员。

⇒ 凡是**必须以普通用户运行**的东西,不要指望任何一种"从提权侧拉起"的办法,
**由人自己双击**,并且**在程序里 fail-closed 地拦住**。
