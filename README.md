## 五分钟版:这是什么

**要解决的问题**:想要一个真正私人的 AI —— 它记得你、能操作你的电脑、能跨设备用,
而**你的数据一个字节都不离开你家**。

**它由三块组成**(装在**一台**主机上,再加任意多台副机):

| | 是什么 | 装在哪 |
|---|---|---|
| **中枢** | 一组本地服务:模型网关 · 显存仲裁 · 局域网身份与准入 · 记忆库 | 只在**主机** |
| **主机管理端** | 一个 Windows 程序,管模型 / 记忆 / 配对 / 起停整套栈 | 只在**主机** |
| **通用客户端** | 一个 Windows 程序,对话 / 翻译 / 同传 —— **主机和副机装的是同一个** | 主机 + 每台副机 |

**说成「两个程序」是上一版文档的错**,而漏掉的那一个(`lan-edge`)正是**副机连不上的原因**。
⇒ 细节见 `00-docs/HANDOVER/00-这是什么与怎么跑起来.md` 第 2 节。

## ★★★ 三件会在第一天骗到你的事

**① 全仓文档一律写 `pwsh -File`,而这台机器上没有 `pwsh`。**
第一条命令就报「无法识别」。换成 `powershell` 能跑。
⇒ `03-别走的弯路.md` 1.1

**② 自检的 exe 有两个候选目录,而旧的那个在盘上真的存在。**
跑错目录**不会给你假的绿,会给你十一条假的红** —— 因为断言读的是磁盘上今天的源码,
而旧 exe 里钉的是一个月前的锚点。**新人会花一天去修一个不存在的回归。**
⇒ 识别特征:PASS 少几百条 + 退出码非 0。命令见 `00-这是什么与怎么跑起来.md` 第 4 节。

**③ `dist\host\` 里最显眼的那份说明文件,教的是一条已经退役的配对路径。**
它让你开一个黑窗口敲命令 —— **那条路今天还能走通**,于是你永远不会发现
管理端里有那一页,也就永远用不到 `dist\admin\`。
⇒ 今天该走的路见 `00-这是什么与怎么跑起来.md`;两份文档打架的原委见 `03-别走的弯路.md`。

## 这个项目为什么这么在意「判据能不能为假」

2026-08-07 那次实机:**门禁 4197 条断言全绿,而核心功能在真机上开不起来。**

从那天起,这个项目的方法论就是一句话 ——

> **跑不了和跑过了必须长得不一样。**

由此长出一整套东西:每条护栏都必须**被红测过**(改坏它,看它真的红);
数字**只写在唯一一处**;更正时**原文划掉不删、带时态留痕**(所以你会看到很多划掉的字,
**那些不是垃圾,是防止你重犯的记录**)。

★ 不理解这一段,你会觉得这个项目过度工程,然后把它拆了。
⇒ **读 `04-门禁与判据体系.md` 第 1 节**,那里有完整的事故经过。
