# P3b S6 — 第二台 Windows PC 实机验收清单

> 需要:主机(已铸 production hub 身份)+ **第二台 Windows PC**(客户端)在同一家庭内网。
> 前置:B17 已裁定(D44,TLS 软件密钥)。开 LAN 用 `lan-firewall.ps1`(你在主机上 elevated 运行)。
> 没有第二台 PC 之前只能标「预验收」,不能签 P3b 完成(决策包 §10 S6)。

## 0. 准备(主机)
- [ ] 铸真身份:`localai-identity init`(一次性;生成 hub CA 在 TPM、服务器叶在软件 KSP)。记下 `hub-id-short`。
- [ ] 开 LAN 防火墙(elevated):`.\90-ops\lan\lan-firewall.ps1 -InterfaceAlias "<你的家用网卡>" -Program "<localai-lan-edge.exe 路径>"`
      —— 网卡须是 **Private**(脚本会拒 Public)。
- [ ] 启动 llama 后端 + 网关(回环)+ LAN Edge(绑选定网卡:8443)。

## 1. 初次配对(双向六词 SAS)
- [ ] 第二台 PC 客户端发现主机,发起配对;两边各显示**六个词**。
- [ ] **肉眼比对两边六词完全一致**再在主机管理端批准(带外比对,决策包 §5)。
- [ ] 批准后客户端 claim + complete → 成为 active 成员;此后 mTLS 直连。
- [ ] ★ 否定:六词**不一致**时拒绝批准 → 配不上(模拟中间人)。

## 2. 断网可用(拔 WAN,只断互联网)
- [ ] 拔掉主机 WAN(只断 uplink;路由器/AP/交换/Wi-Fi/DHCP/本地链路仍在)。
- [ ] WAN 已断时:已配对客户端**新建业务连接仍可用**。
- [ ] WAN 已断时:主机与客户端**都重启**后仍能重新连接。
- [ ] WAN 已断时:一台**未配对**设备仍能走完初次配对。

## 3. 网络变化
- [ ] 换 DHCP 地址后客户端重新发现,**无需重新配对**。

## 4. 撤销(即时)
- [ ] 主机吊销第二台设备 → 该设备**新请求立即被拒**;其它设备不受影响。
- [ ] **流式响应进行中**吊销 → 该设备的流被中止(SLO 2s 内)。

## 5. 暴露面(从第二台 PC 扫)
- [ ] 只有 `8443/TCP` 可达;`8080`(网关)、llama、PG、Qdrant、embedding **全部不可达**。
- [ ] 未选择的网卡 / Public profile **不可达**。
- [ ] 无路由器端口转发 / UPnP / DDNS。
- [ ] 非授权 LAN 主机直接扫 8443:无客户端证书 → 业务被拒(只 `/pair/*` 在开窗时可达)。

## 6. 权限回归(P3a 不被放宽)
- [ ] LAN 设备可读 S0/S1 记忆;**不能**读 S2 / 编辑记忆 / 碰 L4 / 主机管理 / 解除 E1。
- [ ] mDNS 被阻断时:`dial_ip + 固定 .local SNI/TargetHost` 回退可用,且**不降级明文/跳过校验**。

## 7. 拒绝且告警
- [ ] 未授权/已吊销访问、配对刷屏、身份伪造 → **拒绝 + 结构化审计 + 主机本地告警**(可在 host-admin 看到)。

---
全部通过 → P3b 可签「完成」。任一项失败 → 记录证据,回到对应节点修。
